# Branching and merge exercise

Use short-lived feature branches from `main`:

1. Create `feature/<change>` from an up-to-date `main`.
2. Commit one focused change and open a pull request into `main`.
3. Review and merge the pull request with a merge commit.
4. For conflicts, update the branch locally, resolve the marked file, run the site check, commit, and push again.
5. Delete the merged branch.

This repository's exercise branches are:

- `feature/branching-strategy`: this guide.
- `feature/tajmahal-copy`: one side of the conflict.
- `feature/kerala-copy`: the other side of the conflict.
